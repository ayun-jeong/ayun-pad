# ayun pad

A4를 세로로 반 접어(105mm 칼럼) 빽빽하게 쓰던 필기 습관을 웹으로 옮기는 노트 앱.

- 사이트: https://ayun-jeong.github.io/ayun-pad/
- 시험 페이지: `public/lab/keys.html`(단축키·한글 입력), `public/lab/print.html`(A4 반접이 인쇄)

## 되는 것

**쓰기** — 줄 맨 앞 `-` + 스페이스 → 꺾쇠 줄. 꺾쇠 줄과 그 대제목은 설정 없이 빨강 + 깊이별 형광펜(빨강·노랑·파랑·초록·보라), 보통 줄은 검정. 빨간 가지선(├─ └─ │) 자동, Tab / ⇧Tab(자식째), ⌘⇧↑↓ 가지 옮기기, `<-` `->` `<|` `|>` `<->` `<|>` `<=` `=>` `<=>` → ← → ↑ ↓ ↔ ↕ ⇐ ⇒ ⇔. 펜 ⌥R ⌥B ⌥K ⌥P ⌥Y ⌥G, 형광펜 ⌥⇧ + 같은 글자, ⌥O 동그라미, 자간 · 행간 · 글꼴(올리기 포함).

**기호 퀵 메뉴** — `=` 뒤 ≤ ≥ ≠ · 분수 · 루트, `+` 뒤 ⊕ ±, `-` 뒤 ⊖ ±. Tab은 첫 칸, ↑로 들어가 ← → · 숫자 · Enter. 그냥 계속 치면 친 기호 그대로. 분수 · 루트는 줄 높이 안에 그려 줄 간격이 그대로(`/분수` `/루트`로도).

**보기 · 인쇄** — 반쪽 보기(⌥2), A4 합침 보기(⌥3), ⌘P로 A4 2단 인쇄 · PDF. 여백 위아래 · 바깥 3mm / 접는 쪽 2mm, 줄 간격은 반쪽 높이에 맞춤.

**동기화** — 이 기기(IndexedDB)에 먼저 저장, 로그인(카카오 · 이메일)하면 Supabase로 실시간 동기화 · 오프라인 병합 · 10분마다 버전 기록 · 휴지통 30일 · 홈 화면 앱.

**넣기 ( / )** — `/표 3x4`, `/연표 2016 10`, `/수직선 10`, `/그래프`, `/수요공급`, `/손익분기점`, `/제품수명주기`, 초성(`/ㅅㅇㄱㄱ`)으로도 찾기. 표 칸 안에서도 꺾쇠 · 자동 색, 반쪽 경계에 걸린 위젯은 다음 반쪽으로.

**그리기 ( ⌥D )** — 자유 경로 화살표(누를 때마다 꺾이고 끝점에서 두 번 눌러 끝, 직각 H · 45° ⇧), 선 · 네모 · 원 · 글상자(안에서도 펜 · 형광펜 · 동그라미). 그림은 줄에 붙어 있어 줄을 끼우거나 행간을 바꿔도 글을 따라가고, 글과 같은 ⌘Z로 되돌린다.

**찾기** — ⌘F: 이 노트(본문 · 표 · 글상자, 위젯 이름표는 찾기만)에서 찾고 고른 곳에만 동그라미 · 밑줄 · 형광펜 · 글자색을 한 번에(한 번의 ⌘Z로 취소), 바꾸기. ⌘K: 과목 · 노트 · 본문 전체 검색(초성, 트리 경로, 그 줄로 가기, 새 노트) · 명령. ⌥C 최근 색 5개. 노트마다 자동 색 · 화살표 변환 끄기. 백업 내보내기 · 가져오기(JSON, 합치기).

## 구조

- `src/editor/` — ProseMirror 편집기. 문서는 블록 목록(줄 = 깊이 + 보통/꺾쇠 + id, 표, 위젯). 자동 색과 가지선은 저장하지 않고 그릴 때 계산(`decorations.ts`). 규칙은 순수 함수(`tree.ts`, `autoStyle.ts`, `rules.ts`, `treeText.ts`, `layout.ts`, `hangul.ts`)
- `src/draw/` — 그림 층. 노트 Yjs 문서의 `shapes` 지도, 점마다 줄 id에 붙인다(`model.ts`)
- `src/store/` — Yjs 문서 + y-indexeddb + Supabase 동기화(`sync.ts`), 검색 색인, 백업
- `supabase/pad.sql` — 테이블 · RLS · 압축 함수(`node scripts/db-apply.mjs <env 파일>`로 적용)

## 시험

```
npm test                 # 규칙 단위 시험
npm run build
npm run e2e              # 1~2단계: 쓰기 · 보기 · 인쇄
npm run e2e:draw         # 4단계: / 메뉴 · 표 · 연표 · 그래프 · 그리기
npm run e2e:find         # 5단계: 찾기 · 일괄 강조 · 전체 검색 · 백업 · 폰 선택 막대
npm run e2e:math         # 기호 퀵 메뉴(= + -) · 분수 · 루트
E2E_ENV=<service role 키가 든 env 파일> npm run e2e:sync   # 3단계: 두 기기 동기화(임시 계정)
```

main에 push하면 GitHub Actions가 시험 → 빌드 → Pages 배포를 한다.
