# ayun pad

A4를 세로로 반 접어(105mm 칼럼) 빽빽하게 쓰던 필기 습관을 웹으로 옮기는 노트 앱.
트리 가지선 자동 생성, 깊이별 자동 펜·형광펜, A4 2단 합침 인쇄, PC·폰 실시간 동기화가 핵심이다.

- 사이트: https://ayun-jeong.github.io/ayun-pad/
- 진행: **0단계 실측** — `lab/keys.html`(단축키·한글 입력), `lab/print.html`(A4 반접이 인쇄)
- 다음: 1단계 쓰기 엔진(Vite + React + TypeScript, Tiptap, Yjs). 앱이 들어오면 GitHub Actions로 빌드해 Pages에 배포한다.
